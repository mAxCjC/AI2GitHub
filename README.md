🚀 AI2GitHub

AI2GitHub 是一款纯前端运行的轻量级 Web 应用，专为 AI 开发者和爱好者设计。它可以将你在任何 AI 工具（如 ChatGPT、Claude、Gemini、DeepSeek 等）中生成的代码，一键推送并部署到你的 GitHub 仓库中。

无需在本地配置 Git 环境，无需打开终端，只需“复制 - 粘贴 - 点击”，即可完成代码的云端托管和网页部署。

✨ 核心亮点

📦 一键推送代码：支持自动创建新仓库，或向已有的仓库追加/更新文件。拥有智能重试机制，告别因为 GitHub 后台延迟导致的上传失败。

🗂️ 多文件轻松管理：直观的 UI 面板，支持自由添加多个文件（如 index.html, style.css, app.js），完美还原 AI 生成的多文件项目结构。

🌐 GitHub Pages 自动部署：一键开启静态网页托管。部署完成后，直接提供在线访问链接，让你的作品瞬间上线（注意：仅支持原生 HTML/CSS/JS 项目直接运行）。

🔒 极致的安全体验：应用完全在浏览器前端运行。你的 GitHub Personal Access Token 仅保存在浏览器本地，绝不经过任何第三方服务器，百分百保障账号安全。

🛠️ 快速上手指南

第一步：获取 GitHub Token

点击工具左侧的“点击前往生成 Token”链接（或访问 GitHub -> Settings -> Developer Settings -> Personal access tokens）。

点击 Generate new token (classic)。

填写描述，并 务必勾选 repo 这一整个大类的复选框（这赋予了工具读写你的代码仓库的权限）。

生成并复制这串以 ghp_ 开头的密钥。

第二步：连接并配置仓库

将复制的 Token 粘贴到软件的输入框中，点击 连接。成功后会显示你的 GitHub 头像。

在 仓库配置 中：

新建仓库：输入一个拉风的名字，可选择是否设为私有 (Private)。

选择已有：从下拉列表中选择你想要更新的老仓库。

如果你的代码是纯静态网页（原生前端），强烈建议勾选 部署后启用 GitHub Pages。

第三步：粘贴 AI 代码

在右侧的 代码文件清单 中，输入文件名（如 index.html）。

将 AI 生成的代码粘贴进对应的输入框。

如果有多个文件，点击 添加文件 继续粘贴。

第四步：一键发射！

点击左侧黑框底部的蓝色大按钮 一键推送到 GitHub。

观察日志面板，等待进度完成。

部署成功后，直接点击下方出现的绿框链接，即可跳转到 GitHub 源码界面或在线网页浏览你的作品！

⚠️ 常见问题排查

❓ 为什么拉取不到仓库列表？
最常见的原因是你的 Token 权限不够。请返回 GitHub 重新生成 Token，并确保完全勾选了 repo 权限。

❓ 为什么访问 GitHub Pages 在线站点显示 404？

原因 1：GitHub 后台构建网页需要 1~2 分钟，请稍等片刻后刷新页面。

原因 2：你的代码是 React 单文件（.jsx），或者缺失了 index.html 首页文件。GitHub Pages 是静态服务器，无法直接运行未编译的 React 代码。如果你希望在线预览，请让 AI 使用 纯 HTML/CSS/Vanilla JavaScript 编写代码。
