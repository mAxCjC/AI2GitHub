GitHub 授权

需在 GitHub 生成，勾选 "repo" 权限。点击前往生成

找不到仓库？(权限说明)

如果连接成功但没拉取到仓库，说明 Token 没有勾选 repo 权限。请按以下步骤配置：

  1. 访问 GitHub -> Settings -> Developer Settings -> Personal access tokens。
  2. 点击你的 Token（或新建）。
  3. 务必勾选 repo 整个大类。
  4. 复制新 Token 填入上方重新连接。
